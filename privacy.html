Rho PDF Privacy Policy

Last updated: August 27, 2026

Local document processing

Rho PDF processes documents locally on your Windows PC. Opening, rendering, searching, printing, merging, splitting, rearranging, and converting PDFs do not upload document contents or filenames.

No advertising or background telemetry

Rho PDF has no advertising, account, cloud synchronization, analytics, or background telemetry. It does not create diagnostic logs containing filenames or document text. Recent-file history, window settings, and optional session state are stored only in the current Windows user profile and can be cleared from the app.

Updates

The user-initiated Help > Check for updates command opens the public Rho PDF release page in the default browser. Rho PDF does not make a background update request or send document information.

Ask Rho

Ask Rho model management may download an official model only after you select a model and start the download. Offline model-package import is also available. Indexing, retrieval, questions, answers, and model inference run locally; document contents, questions, answers, and indexes are not uploaded.

Network access

User-initiated model downloads and opening the update page are the only network-capable product paths in the current release. Opening the app, opening documents, indexing, searching, and local inference do not initiate network requests.

Contact

For privacy questions, email xnuapp@gmail.com.
